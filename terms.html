利用規約

kotodama-metrics（投稿成果の自動集計ツール）　制定日・最終更新日：2026年10月13日

1. 本アプリについて

「kotodama-metrics」（以下「本アプリ」）は、運営者（BODY & MIND）が、自分で運営する YouTube チャンネルと Instagram アカウントの投稿成果を集計するために作った個人用のツールです。一般の方への提供は行っていません。

2. YouTube 利用規約への同意

本アプリは YouTube API サービスを使用しています。本アプリを利用することにより、利用者は YouTube 利用規約（https://www.youtube.com/t/terms）に拘束されることに同意したものとみなされます。

Google による情報の取り扱いについては、Google プライバシーポリシー（http://www.google.com/policies/privacy）をご覧ください。

3. 情報の取り扱い

本アプリが取得・保存する情報とその取り扱いは、プライバシーポリシーに定めるとおりです。

4. 禁止事項

本アプリを、YouTube・Google・Instagram（Meta）の規約に反する目的で使用してはなりません。

5. 免責

本アプリが集計する数値は、各サービスの API が返した値をそのまま記録したもので、正確性・完全性を保証するものではありません。各サービスの仕様変更などにより、本アプリが予告なく利用できなくなる場合があります。

6. 変更

本規約を変更する場合は、このページを更新し、更新日を記載します。
