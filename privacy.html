アプリについてプライバシーポリシー利用規約

プライバシーポリシー

kotodama-metrics（投稿成果の自動集計ツール）　制定日：2026年10月13日　最終更新日：2026年10月13日（週次レポートの追加）

このポリシーは、運営者（BODY & MIND）が自分で使う集計ツール「kotodama-metrics」（以下「本アプリ」）が、どの情報を取得し、どのように使い、保存し、共有するかを説明するものです。

1. YouTube API サービスの使用

本アプリは YouTube API サービス（YouTube Data API・YouTube Analytics API）を使用しています。Google による情報の取り扱いは、Google プライバシーポリシー（http://www.google.com/policies/privacy）をご覧ください。

2. 取得する情報

本アプリが取得するのは、運営者が自分で許可した、運営者自身のチャンネル・アカウントの情報だけです。

YouTube のチャンネル情報チャンネルID、ハンドル（@名）、アップロード動画の一覧のID。許可したチャンネルが設定どおりかを確認するために使います。
YouTube の動画情報動画ID、題名、公開日時、長さ
YouTube の統計視聴回数、エンゲージ視聴回数、総再生時間、平均視聴時間、平均視聴率、高評価数、コメント数、共有数、登録者の増加数・減少数（YouTube Analytics API）、公開されている視聴回数・高評価数・コメント数（YouTube Data API）。日ごとの視聴回数・平均視聴率・登録者の増加数／減少数、動画内の経過位置ごとの視聴者維持率と、YouTube が示す類似動画との比較の値、流入元（検索・関連動画など）ごとの視聴回数・総再生時間（YouTube Analytics API）
Instagram の情報運営者のアカウント（@kotodama_kaiun）のリールの ID・URL・投稿日時・キャプションの1行目と、再生数・リーチ・いいね・コメント数・保存数・シェア数・平均視聴時間などの数値（Instagram API）

コメントの本文、視聴者やフォロワーの個人を特定できる情報、収益に関する情報、メールアドレスなどは取得しません。

3. 利用目的

取得した情報は、運営者が自分の投稿の成果を把握し、次の制作の参考にするためだけに使います。具体的には、公開から24時間後・7日後の数値の記録、同じチャンネル（アカウント）の前の投稿との比較を含む運営者向けレポートの作成、運営者への通知に使います。

週に1回、チャンネルごとに別々の週次レポートを作ります。YouTube の値は YouTube API の値をそのまま表示し、合計・差・割合などの新しい数値は作りません。異なるチャンネルのデータを合わせた集計もしません。

4. 保存場所と保存期間

集計データ・レポート運営者だけがアクセスできる GitHub の非公開リポジトリに保存します。YouTube API の応答は、統計の部分だけを保存します。YouTube の動画の題名は集計用の一覧にだけ記録し（7日ごとに最新の内容に更新）、記録・レポート・通知では動画IDで表します。
予備の保存集計の実行ごとに、GitHub Actions の予備保存（アーティファクト）にも保存し、90日で自動的に削除されます。
通知GitHub の Issue（非公開リポジトリ内）にコメントし、GitHub から運営者にメールが届きます。通知に含まれるのは、レポートの名前、新しく追加した投稿の URL（Instagram はキャプションの1行目、YouTube は動画ID）、取得できなかった投稿、注意事項です。
実行の記録集計プログラムの実行の記録（ログ）は GitHub に保存されます（GitHub の既定で90日）。ログには認証情報を出さず、YouTube の動画は動画IDで表します。
認証情報Google（YouTube）の認証情報は GitHub Secrets（暗号化された保管場所）に、Instagram と GitHub の認証情報は GitHub Secrets と運営者の Mac のキーチェーンに保存し、画面・ログ・ファイルには出力しません。Google の認証情報の設定時に一時的にダウンロードするファイルは、登録後に削除します。

保存した YouTube のデータの確認と更新：本アプリは7日ごとに、許可がまだ有効か、動画がまだ存在するかを YouTube API で確認し、自動で登録した動画の題名・長さを最新の内容に更新します。動画が見つからない場合や、許可を確認できない場合は運営者に通知し、運営者がその動画（またはチャンネル）のデータを削除します。収集を停止しているなどの理由で確認ができない状態が続く場合も、運営者に通知し、収集の再開またはデータの削除を行います。

5. 第三者への提供

取得した情報を販売したり、第三者に提供したり、広告に使ったりすることはありません。ただし、本アプリの実行・保存・通知のために、GitHub（GitHub, Inc.）のサービスを利用しており、情報は GitHub のサーバー上で処理・保存されます。また、YouTube のデータは Google から、Instagram のデータは Meta から取得します。法令にもとづく開示を求められた場合は、法令に従います。

6. 情報を見る人

情報を見るのは運営者本人だけです。

7. Google API サービスのユーザーデータに関するポリシー

本アプリによる、Google API から受け取った情報の使用および他のアプリへの転送は、限定使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

8. Cookie など

本アプリ（集計プログラム）は、利用者の端末やブラウザに Cookie や類似の技術を設定・読み取りしません。

9. アクセスの取り消しと、データの削除

本アプリへの YouTube のアクセス許可は、いつでも Google アカウントのセキュリティ設定（サードパーティのアクセス）（https://security.google.com/settings/security/permissions）から取り消すことができます。

許可が取り消された場合、または下記のお問い合わせ先から削除の依頼があった場合は、30日以内に、本アプリが保存した該当チャンネル（または該当動画）の YouTube のデータを、非公開リポジトリの現在のデータ、変更履歴（過去の版）、予備の保存から削除します。
