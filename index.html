kotodama-metrics

投稿成果の自動集計ツール（運営者の個人用）

このアプリについて

kotodama-metrics は、運営者（BODY & MIND）が自分で運営しているYouTubeチャンネルとInstagramアカウントについて、投稿した動画の成果（視聴回数など）を、公開から24時間後と7日後に自動で集計し、運営者向けのレポートを作るためのツールです。

運営者本人だけが使うツールで、一般の方に向けたサービスではありません。ログイン画面や会員登録はありません。

対象のアカウント

  • YouTube：魂響の言霊〜心をやすめる言葉の神社〜（@kotodama-poem）
  • YouTube：自然と音の瞑想屋（@wave_space2025）
  • Instagram：@kotodama_kaiun

Google（YouTube）で許可を求める範囲

本アプリは YouTube API サービスを使用しています。許可を求めるのは、次の読み取りだけの2つです。

youtube.readonly自分のチャンネルの確認（許可したチャンネルが設定どおりかの確認）、アップロードした動画の一覧・題名・公開日時・長さ・公開されている視聴回数などの取得
yt-analytics.readonly自分の動画ごとの分析の数値（視聴回数、総再生時間、平均視聴時間、平均視聴率、高評価、コメント数、共有数、登録者の増減など）の取得

動画の投稿・編集・削除、コメントの投稿など、YouTube上のデータを変更する権限は求めません。

このアプリがしないこと

  • YouTube・Instagramへの投稿、編集、削除
  • 運営者以外の方のアカウントのデータの取得
  • 取得したデータの販売、第三者への提供、広告への利用
